# SEO workflow cheatsheet — z-seo-plan

Quick reference while executing Phase 1–2.

## Seed recipe

From product truth, generate seeds in **searcher language**:

| Pattern | Example shape |
|---------|----------------|
| Problem | `how to {pain}`, `{pain} tool` |
| Audience + job | `{role} {job} software` |
| Category | `best {category} for {niche}` |
| Alternative | `{competitor} alternative` |
| Comparison | `{a} vs {b}` |
| Feature | `{feature} for {audience}` |
| Local/lang | CN: `有没有…`, `…推荐`, `…替代` |

## Intent quick labels

| Intent | User wants | Typical page |
|--------|------------|--------------|
| Informational | Learn | Blog, docs, guide |
| Commercial | Compare options | Landing, comparison, listicle alternative |
| Transactional | Act now | Pricing, signup, install |
| Navigational | Find a brand | Brand home |

## Difficulty heuristics (no paid tools)

| Signal | Suggests |
|--------|----------|
| Page 1 = giant brands + Wikipedia + massive pubs | High difficulty |
| Page 1 = thin blogs, forums, small tools | Lower difficulty / opportunity |
| Exact-match domains + heavy ads | Commercial competitive |
| Strong PAA / many question queries | Long-tail content opportunity |
| Query matches your unique wedge language | Higher relevance even if smaller |

## Demand heuristics (no paid tools)

| Signal | Suggests |
|--------|----------|
| Rich autocomplete / many related queries | Some demand |
| Repeated in Reddit/HN/community in same wording | Real problem language |
| Trends up over 12 months | Growing interest |
| Zero related, empty SERP forums | Weak or brand-new niche |

## Cannibalization check

If two URLs could rank for the same primary intent → merge, differentiate, or
301/canonical strategy. One primary intent per URL.
