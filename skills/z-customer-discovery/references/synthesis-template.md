## 6. Gate scores

Use the same anchors for every gate:

| Score | Evidence anchor |
|-------|-----------------|
| 1 | Evidence repeatedly contradicts the gate, or the behavior is absent |
| 2 | Isolated or weak support; most interviews are neutral/contradictory |
| 3 | Mixed evidence; a plausible segment exists but the pattern is not stable |
| 4 | Repeated behavioral support across independent interviews |
| 5 | Repeated, strong behavior with concrete cost/action and few material contradictions |

Score the evidence, not the founder's enthusiasm. Confidence is separate: base
it on sample diversity, note quality, bias, and saturation—not on the numeric
score itself.

## 8. Evidence handoff

In the final `Evidence classes` cell, delete non-applicable choices and keep only
canonical class names without qualifiers.

The seven first-column labels below are literal interface tokens. Copy them as
plain text with no Markdown styling, code ticks, links, punctuation, translation,
or synonyms. Valid: `| Current decision |`. Invalid:
`| **Current decision** |`.

| Field | Value |
|-------|-------|
| Current decision | Advance / Reshape / Park |
| Evidence classes | primary behavior / observed experiment / secondary public / search signal / assumption |
| Supported claims | Claims supported by cited interview behavior |
| Still unproven | Payment, switching, scale, or retention not established by this sample |
| Contradictions / exclusions | Polite-only segments, killed ideas, and counterexamples |
| Source anchors | Note ids, short quotes, and upstream artifact paths |
| Next validation | One action + owner + success/fail signal |

Preserve small-sample limits. Interview enthusiasm does not become payment or
retention evidence when passed to smoke, PRD, or SEO work.
