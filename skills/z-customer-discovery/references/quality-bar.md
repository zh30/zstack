# Quality bar — z-customer-discovery

## Setup must pass

- [ ] Narrow ICP + anti-ICP  
- [ ] Falsifiable G1/G2/G3 hypotheses  
- [ ] Recruit scripts + screening  
- [ ] Interview guide biased to past behavior  
- [ ] Target N (5–15) and cold/warm mix stated  
- [ ] Next outreach actions concrete  

## Debrief must pass

- [ ] At least one concrete past incident  
- [ ] Status quo tools/hacks named  
- [ ] Mom Test audit filled (even if “clean”)  
- [ ] Gate deltas not all “support” without quotes  
- [ ] No invented details  
- [ ] The debrief ends with the one fixed two-column Evidence handoff table

## Synthesize must pass

- [ ] N and biases stated  
- [ ] Patterns tied to note ids / quotes  
- [ ] G1/G2/G3 scored with confidence  
- [ ] Explicit Advance / Reshape / Park  
- [ ] Evidence handoff is one seven-row table with every exact template label
- [ ] Evidence handoff has exactly two columns headed `Field | Value`; no
      evidence-class, status, or detail column is added
- [ ] Every handoff label is plain first-column text with no bold, italics,
      code, link, punctuation, translation, or synonym
- [ ] `Evidence classes` contains only applicable canonical class names;
      sample and provenance limits stay visible elsewhere in the table, and
      planned future interviews do not add a current class
- [ ] `Evidence classes` is never empty; compliment-only notes use `assumption`
- [ ] No market-size fantasy from N=10  

## Instant fail

- Fake interviews or persona theater as evidence  
- Synthesis from compliments only  
- Green-light large build with N&lt;5 and no smoke  
- Styled, translated, punctuated, or renamed Evidence handoff labels
- Missing, duplicated, or three-column Evidence handoff in any mode
