# Quality bar — Z Skill Name

Run this checklist before delivering the primary artifact.

## Must pass

- [ ] The requested independent-developer outcome and scope are explicit
- [ ] Inputs, assumptions, blocked sources, and exclusions are visible
- [ ] Decisions follow from cited evidence rather than invented confidence
- [ ] Evidence handoff is exactly one `Field | Value` table with seven exact
      plain-text field labels and applicable canonical evidence classes only
- [ ] Planned future validation does not add an evidence class to the current handoff
- [ ] `Evidence classes` is never empty; `assumption` covers evidence-free inputs
- [ ] The next validation is concrete, bounded, and resolves an open claim

## Instant fail

- Invented sources, observations, measurements, quotes, or certainty
- Assumptions or weak signals presented as customer behavior, payment, or retention
- Result fields filled before the relevant test or research happened
- No usable artifact, decision, or next action for a solo developer

## Definition of done

A solo developer can use the artifact immediately and can tell what is known,
what is assumed, and what must be validated next.
