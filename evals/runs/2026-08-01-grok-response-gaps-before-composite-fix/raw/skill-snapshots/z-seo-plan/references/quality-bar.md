# Quality bar — z-seo-plan

## Must pass

- [ ] Inputs stated (PRD and/or URL and/or code paths)  
- [ ] **One clear primary keyword** with intent + target page  
- [ ] Secondary + long-tail lists are **clustered**, not a flat dump  
- [ ] Every P0 keyword maps to a **page or planned URL**  
- [ ] Demand/difficulty use **bands + evidence**, not fake exact volumes  
- [ ] SERP or public-web research was actually attempted (or limits documented)  
- [ ] **Avoid list** present (what not to chase)  
- [ ] Indie-winnability considered (not only “big volume”)  
- [ ] 7-day actions are concrete and shippable by one person  
- [ ] White-hat only  
- [ ] Evidence handoff is one seven-row table with every exact template label
- [ ] `Evidence classes` contains only applicable canonical class names; the
      other rows keep search opportunity separate from product, payment,
      ranking, traffic, and conversion proof

## Anti-patterns (rewrite)

| Anti-pattern | Fix |
|--------------|-----|
| 50 keywords, no priority | Force primary + P0/P1/P2 |
| Exact monthly volume with no tool | Use bands + evidence |
| “Rank #1 for AI” style head terms only | Add long-tail + gap analysis |
| Keywords with no page map | Assign URLs |
| Generic SEO textbook pasted | Tie every note to this product |
| Black-hat suggestions | Remove; explain risk |

## Definition of done

A solo founder can answer:

1. What is my main keyword and page?  
2. Which 3 long-tails do I publish first?  
3. What should I stop wasting time on?  
4. What do I do this week?
