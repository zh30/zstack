# Quality bar — z-market-validate

Run this checklist before delivering the report.

## Must pass

- [ ] Narrow ICP, geography, assumptions, and channel coverage are explicit
- [ ] Supporting and disconfirming signals both cite sources or blocked limits
- [ ] Competition intensity is inverted before calculating the composite
- [ ] The formula, score table, executive summary, and later prose reuse one
      identical two-decimal composite value
- [ ] Commercial value, indie fit, and 30–90 day return are judged separately
- [ ] One primary wedge and an explicit do-not-start list are present
- [ ] Exactly three next-48-hour actions are concrete and bounded
- [ ] Evidence handoff is one seven-row table with every exact template label
- [ ] `Evidence classes` contains only applicable canonical class names;
      qualifiers belong with claims or anchors

## Instant fail

- Invented links, quotes, volume, revenue, or demand confidence
- Upvotes or competitor pricing presented as primary customer/payment evidence
- Positive-only research, raw competition averaged as favorable, or no indie lens
- Conflicting composite values anywhere in the same report
- Unavailable channels silently treated as searched

## Definition of done

A solo founder can decide whether to deepen, reshape, park, or avoid the idea and
can run the next validation without mistaking secondary research for proof.
