# Prompt

## prd-evidence-rich-mvp

> Write a six-week solo-developer MVP PRD for an ownership-aware client-onboarding runbook for small agencies. Discovery supports explicit owners, reusable steps, external record links, and CSV, while sensitive file storage and bookkeeping are separate. Cold smoke traffic produced 27 signups from 300 visits and two pilot volunteers; warm traffic was 12 of 40 and must stay separate. No payment was requested, so $29/month is only a hypothesis. P0 includes one workflow, one live run, owners/due states, completion/exceptions, manual reminders, links, CSV, and missed-step history. Exclude portals, files, migration, connectors, AI, mobile, enterprise roles, and compliance scope. Include evidence treatment, requirements with acceptance criteria, journeys and states, data boundaries, metrics/kill triggers, milestones, and the first vertical slice.
