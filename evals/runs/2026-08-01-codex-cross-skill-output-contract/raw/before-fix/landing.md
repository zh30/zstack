## 2. Source-specific thresholds

Do not make a source decision until its minimum qualified-visitor sample is reached.

| Traffic class | Minimum visitors | Pass | Pivot signal |
|---|---:|---:|---:|
| `warm_outreach` | 40 | ≥12 confirmed, plus ≥5 substantive replies | ≤4 confirmed |
| `cold_reddit` | 80 | ≥7 confirmed | ≤2 confirmed |
| `cold_niche` | 50 | ≥6 confirmed | ≤2 confirmed |
| `cold_x` | 60 | ≥4 confirmed | ≤1 confirmed |
| `paid_reddit` | 100 | ≥5 confirmed and ≤$30 per confirmation | ≤2 confirmed, or >$50 per confirmation after $100 spent |

Below the minimum sample means **inconclusive**, not failure.

Proceed to a thin MVP only if:

- At least two cold classes pass independently.
- Those passing cold classes produce at least 12 confirmed subscribers.
- At least five cold subscribers provide a concrete workflow or workaround.
- At least three cold subscribers express credible willingness to pay around $9/month.
- Warm results are shown separately and never used to improve cold conversion rates.

If two adequately sampled cold sources hit their pivot bars, reshape the ICP or promise and run one controlled second test. Park the idea only if the second test also fails.

## 4. Buttondown proxy

Save as `functions/api/waitlist.js`:

```js
const MAX_LENGTH = 100

function clean(value, limit = MAX_LENGTH) {
  return typeof value === "string" ? value.trim().slice(0, limit) : ""
}

function classify(input) {
  if (input.utm_source === "warm_outreach") return "warm_outreach"
  if (input.utm_source === "reddit" && input.utm_medium === "paid_social") return "paid_reddit"
  if (input.utm_source === "reddit" && input.utm_medium === "community") return "cold_reddit"
  if (input.utm_source === "support_community") return "cold_niche"
  if (input.utm_source === "x" && input.utm_medium === "social") return "cold_x"
  return "unknown"
}

function json(body, status = 200) {
  return new Response(JSON.stringify(body), {
    status,
    headers: {
      "content-type": "application/json; charset=utf-8",
      "cache-control": "no-store"
    }
  })
}

export async function onRequestPost(context) {
  let input

  try {
    input = await context.request.json()
  } catch {
    return json({ accepted: false, message: "Invalid request." }, 400)
  }

  if (clean(input.company_website)) {
    return json({ accepted: false, message: "Request received." }, 202)
  }

  const email = clean(input.email, 254).toLowerCase()
  const emailPattern = /^[^\s@]+@[^\s@]+\.[^\s@]+$/

  if (!emailPattern.test(email)) {
    return json({ accepted: false, message: "Enter a valid work email." }, 400)
  }

  const startedAt = Number(input.started_at)
  if (!Number.isFinite(startedAt) || Date.now() - startedAt < 1200) {
    return json({ accepted: false, message: "Please try again." }, 400)
  }

  const attribution = {
    utm_source: clean(input.utm_source) || "direct",
    utm_medium: clean(input.utm_medium) || "none",
    utm_campaign: clean(input.utm_campaign) || "none",
    utm_content: clean(input.utm_content) || "none",
    utm_term: clean(input.utm_term) || "none"
  }

  const trafficClass = classify(attribution)

  const response = await fetch("https://api.buttondown.email/v1/subscribers", {
    method: "POST",
    headers: {
      authorization: `Token ${context.env.BUTTONDOWN_API_KEY}`,
      "content-type": "application/json"
    },
    body: JSON.stringify({
      email_address: email,
      metadata: {
        traffic_class: trafficClass,
        ...attribution,
        switching_pain: clean(input.pain, 300),
        smoke_version: "clienttab_202608"
      }
    })
  })

  if (response.ok) {
    return json({ accepted: true })
  }

  if (response.status === 400 || response.status === 409) {
    return json({
      accepted: false,
      message: "That address could not be added or may already be registered. Check your inbox or try another address."
    }, 409)
  }

  console.error("Buttondown subscriber request failed", {
    status: response.status,
    trafficClass
  })

  return json({
    accepted: false,
    message: "The waitlist is temporarily unavailable. Please try again."
  }, 502)
}

export function onRequest() {
  return json({ accepted: false, message: "Method not allowed." }, 405)
}
```

## 6. Events and sources of truth

| Event/record | Meaning | Decision use |
|---|---|---|
| Plausible pageview | Landing viewed | Denominator |
| `click_cta` | CTA clicked | Friction diagnostic |
| `attempt_waitlist` | Valid client-side form attempted | Operational only |
| `waitlist_provider_accepted` | Buttondown API accepted address | Funnel diagnostic only |
| Buttondown active/confirmed subscriber | Double opt-in completed | Primary conversion |
| Buttondown reply | Pain, workaround, price intent | Strong qualitative signal |

Configure Plausible goals for the three custom events. Use Buttondown’s confirmed subscriber export as the conversion numerator, grouped by `traffic_class`. Never report `waitlist_provider_accepted` as a confirmed signup.

Test before launch:

1. Valid email from every UTM class.
2. Invalid email.
3. Duplicate email.
4. Filled honeypot.
5. Buttondown outage or invalid API key.
6. Double-opt-in confirmation.
7. Metadata present on confirmed subscriber export.
8. Plausible CTA, attempt, and accepted events.
9. Mobile keyboard, focus, status announcement, and form reset behavior.

## 10. Decision matrix

| Result | Decision |
|---|---|
| Two or more cold sources pass, with workflow and price replies | Write a thin PRD and build only save/list/restore |
| One cold source passes; others inconclusive | Extend only the inconclusive qualified channel |
| One cold source passes; others fail | Interview that source before deciding whether the ICP is narrower |
| Good confirmed CVR but few replies | Treat as soft curiosity; interview before building |
| Organic passes but paid fails | Continue discovery through organic channels; do not claim scalable acquisition |
| Paid passes but organic fails | Inspect ad-message matching and signup quality before building |
| Two sampled cold sources fail | Retest one new promise or narrower ICP |
| Second controlled test also fails | Park or materially reshape the idea |
| Warm passes while cold fails | Record warm support separately; do not claim broad demand |
