## 1. Smoke protocol

| Item | Definition |
|------|------------|
| **Hypothesis** | If we offer early access to a simple waitlist + demand-smoke toolkit for solo builders who waste months shipping unvalidated products, ≥3% of qualified cold visitors will leave email within 14 days. |
| **Primary metric** | Confirmed waitlist signups ÷ unique qualified visitors (provider-confirmed only). |
| **Secondary** | CTA clicks; welcome open rate (if double opt-in / welcome send); reply rate to “why do you need this?”; source via UTM. |
| **Sample plan** | Target ≥200 qualified visits from ≥2 cold/controlled channels before kill/continue. Do **not** pool warm DMs with cold Reddit into one headline CVR. |
| **Success bar (directional)** | Cold traffic: ≥3–5% visitor→confirmed email; or ≥15 confirmed emails + ≥3 substantive “I’d use/pay” replies. Warm network: treat separately (expect higher CVR). |
| **Kill / pivot** | After ≥200 qualified visits and ≥2 copy/channel attempts, sustained **&lt;1–2%** cold email CVR and no engaged replies → reshape offer/ICP; do **not** build the product. |
| **Timebox** | Day 0 ship page → Days 1–14 traffic → Day 14 decision. |

**Instrumentation events (distinct):** page view → CTA click → form attempt → **provider-confirmed signup** → reply / “I’d pay”. Never treat attempt as conversion.

## 3. Implementation pack (lowest cost)

| Choice | Recommendation |
|--------|----------------|
| **Tier** | A: single `index.html` + Formspree / Basin / Getform (or Google Form embed) |
| **Fields** | `email` (required); optional `name`; optional `biggest_pain`; hidden `utm_source`, `utm_medium`, `utm_campaign` |
| **Success UI** | Fire-and-forget cross-origin form: **“Submission sent — check your inbox if the provider accepts it.”** Only show “You’re on the list” after verified provider callback / confirmed subscriber record. |
| **Opt-in** | Double opt-in if EU/heavy deliverability needs; single opt-in OK for many US indie tests — pick for list quality, not speed alone. |
| **Analytics** | Plausible or Umami: pageview + CTA click. **Do not** fire “conversion” on submit click; use provider confirmed list as source of truth. |
| **UTM** | `?utm_source=x|reddit|ih|warm&utm_medium=social|dm|community&utm_campaign=signal_smoke_20260801` |
| **Placeholders** | `FORM_ENDPOINT`, `ANALYTICS_ID`, `CONTACT_EMAIL` — not wired until you paste real IDs. |

**Evidence limit this run:** no web/browser/deploy tools; no live form wiring; no measured traffic. Anything “2,000 users / logos convert better” is **assumption**, not evidence.

| Result | Next step |
|--------|-----------|
